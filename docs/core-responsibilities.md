# Core Responsibilities

**Security Architecture is responsible for:**
- Defining secure design principles and patterns
- Performing security threat modelling
- Advising on solution design and technical risks
- Creating security design artefacts (HLD/LLD contributions)
- Supporting risk assessment inputs during early project phases
- Leading security architecture reviews
